# Frontend

AOP 프로젝트의 프론트엔드입니다.

## 빠른 시작

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

개발 서버는 `http://localhost:5173`에서 실행됩니다.
